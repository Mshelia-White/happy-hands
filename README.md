# Happy Hands Foundation - Website Project

A fast, responsive, and modern static HTML5/CSS3/JavaScript website for the **Happy Hands Foundation**, an organization dedicated to 360-degree child welfare, education, and health in Nigeria.

---

## 📄 Page Index & Descriptions

| Page | File | Purpose |
| :--- | :--- | :--- |
| **Home** | `index.html` | Primary landing page featuring the hero banner, interactive impact counter, program highlights, live donation widget, gallery, and testimonials. |
| **About Us** | `about.html` | The origin story, mission & vision cards, and the founder's guiding vision. |
| **Programs Overview** | `programs.html` | High-level summary of the two pillars (Education and Health) with direct links to all five sub-initiatives. |
| **Scholars Program** | `scholars-program.html` | Education pillar initiative providing merit and need-based scholarships covering tuition, supplies, and mentorship. |
| **Teachers on the Go** | `teachers-on-the-go.html` | Education pillar outreach deploying volunteer instructors to teach soft skills, financial literacy, and personal development. |
| **Back-2-School** | `back-2-school.html` | Education pillar project providing school bags, books, stationery, desks, and classroom equipment. |
| **Nourish Now** | `nourish-now.html` | Health pillar initiative distributing "Happy Boxes", "Eat 'n' Learn" meals, and emergency food supplies. |
| **FitTot** | `fittot.html` | Health pillar healthcare initiative connecting children to medical screenings, basic care, and HMO partnerships. |
| **Volunteer** | `volunteer.html` | Comprehensive volunteer hub detailing virtual roles, physical roles, specialized positions, and FAQ. |
| **Contact Us** | `contact.html` | Contact form, physical office location, phone, email, and social channels. |

## 🚀 Deployment

This project is 100% pure static HTML/CSS/JS and can be hosted anywhere:
- **GitHub Pages** (Settings > Pages > Deploy from branch `main` / `root`)
- **Netlify / Vercel** (Drag & drop or connect repo)
- **cPanel / Apache / Nginx** (Upload root folder to `public_html`)
